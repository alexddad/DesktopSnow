# ❄️ Desktop Snow — Новогодний интерактивный снег на окнах Windows

Праздничное, атмосферное и производительное приложение для Windows, создающее живой снегопад прямо поверх окон рабочего стола с физикой осыпания, гирляндами и украшениями!

---

## ✨ Главные возможности

1. **Снег ложится только на открытые окна**:
   - Приложение автоматически отслеживает окна (браузеры, мессенджеры, проводник, редактор кода).
   - Снежинки мягко приземляются на верхние границы окон и образуют реалистичные сугробы.
   - Снег за окнами переднего плана аккуратно отсекается (не накладывается друг на друга).

2. **Живая физика при движении окон**:
   - Подвигайте или потрясите окно — снег осыпается вниз градом хлопьев и снежной пыли с учётом инерции!
   - При закрытии или сворачивании окна сугроб плавно осыпается вниз.

3. **Интерактив с мышью**:
   - Проведите курсором по сугробу, чтобы **смахнуть снег** в этом месте.
   - Падающие снежинки мягко огибают курсор мыши.

4. **100% прозрачность для кликов (Click-Through)**:
   - Приложение совершенно не мешает работе или играм: сквозь снег можно свободно кликать, печатать, выделять текст и перетаскивать окна (`WS_EX_TRANSPARENT`).

5. **🎄 Праздничные украшения и эффекты**:
   - **Новогодняя гирлянда** на шапках окон с цветными мерцающими лампочками, покачивающимися при движении.
   - **Миниатюрная ёлочка с подарками** на широких окнах.
   - **Искры и блёстки** на свежем снегу.

6. **Управление через системный трей (возле часов)**:
   - 🌨️ Регулировка интенсивности (Легкий снежок / Обычный / Метель).
   - 💨 Настройка ветра.
   - 🎄 Переключение режимов гирлянды и украшений.
   - ⏸️ Пауза / ❌ Выход.

## 📥 Как скачать и запустить

### Вариант 1. Запуск из архива (самый простой)
1. Нажмите зелёную кнопку **`<> Code`** вверху этой страницы и выберите **`Download ZIP`**.
2. Распакуйте скачанный архив в любую удобную папку.
3. Запустите файл **`start_snow.bat`**:
   - Скрипт сам проверит наличие Python и автоматически установит нужные библиотеки (`PyQt6`) при первом запуске!
4. Для бесшумного запуска без чёрного окна консоли используйте **`start_silent.vbs`**.
5. Чтобы создать удобный ярлык на Рабочем столе — запустите **`create_desktop_shortcut.bat`**.

---

### Вариант 2. Для разработчиков (Git)
```bash
git clone https://github.com/ВАШ_НИК/DesktopSnow.git
cd DesktopSnow
pip install -r requirements.txt
python main.py
```

---

## 📦 Сборка в один файл .exe (без необходимости ставить Python)
Если вы хотите отправить программу друзьям, у которых не установлен Python:
1. Запустите скрипт **`build_exe.bat`**.
2. В созданной папке `dist/` появится файл **`DesktopSnow.exe`**, который можно запускать на любом компьютере с Windows 10/11 в один клик!

---

## 🛑 Как остановить программу
- Через контекстное меню иконки снежинки в **системном трее** (возле часов Windows) ➔ **Выход**.
- Либо запустив файл **`stop_snow.bat`** в папке проекта.
